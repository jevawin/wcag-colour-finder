From colour-engine.js:
```javascript
export const AA_NORMAL  = 4.5;
export const AAA_NORMAL = 7.0;
export const AA_LARGE   = 3.0;
export const AAA_LARGE  = 4.5;

export function parseHex(hex)                // returns {r, g, b} or null
export function contrastRatio(hex1, hex2)     // returns raw float, e.g. 4.478
export function passesAA(ratio)              // ratio >= 4.5
export function passesAAA(ratio)             // ratio >= 7.0
export function passesAALarge(ratio)         // ratio >= 3.0
export function passesAAALarge(ratio)        // ratio >= 4.5
```

Conventions from Phase 1:
- parseHex accepts 3-digit, 6-digit, with/without #. Returns null on invalid.
- contrastRatio returns raw float — NEVER round before threshold check.
- Store hex without # prefix. Call contrastRatio('#' + hex, BG).
- American spelling in code identifiers (color), British in UI text (colour).

Then create app.js (GREEN phase):

**Exported pure functions** (testable without DOM):

1. `buildBadgeState(ratio)` — calls passesAA, passesAAA, passesAALarge, passesAAALarge from colour-engine.js, returns plain object `{ aa, aaa, aaLarge, aaaLarge }` (all booleans).

2. `expandHex(hex)` — if hex.length === 3, expand each char (e.g. 'abc' -> 'AABBCC'). Otherwise return hex.toUpperCase(). No validation — parseHex already validated.

3. `formatRatio(ratio)` — returns `ratio.toFixed(2) + ':1'`.

**DOM wiring** (runs only in browser, not during node:test):

Guard the DOM code with:
```javascript
if (typeof document !== 'undefined') {
  // all DOM code here
}
```

Inside the guard:

Constants:
```javascript
const LIGHT_BG = '#ffffff';
const DARK_BG  = '#111111';
const HEX_DEFAULT = '2563EB';
```

Element references (querySelector once):
- `hexInput` = `#hex-input`
- `errorMsg` = `#hex-error`
- `lightPanel` = `.panel--light`
- `darkPanel` = `.panel--dark`

`render(hex)` function:
1. Set `--user-colour` on documentElement to `'#' + hex`
2. Calculate `ratioLight = contrastRatio('#' + hex, LIGHT_BG)` and `ratioDark = contrastRatio('#' + hex, DARK_BG)`
3. Call `updatePanel(lightPanel, ratioLight)` and `updatePanel(darkPanel, ratioDark)`

`updatePanel(panelEl, ratio)` function:
1. Set `.ratio` textContent to `formatRatio(ratio)`
2. Get badge state via `buildBadgeState(ratio)`
3. Call `setBadge` for each of `.badge-aa`, `.badge-aaa`, `.badge-aa-lg`, `.badge-aaa-lg` with the corresponding boolean

`setBadge(root, selector, passes, label)` function:
- `label` is 'AA' or 'AAA'
- `el.textContent = (passes ? 'Pass ' : 'Fail ') + label`
- `el.classList.toggle('badge--pass', passes)`
- `el.classList.toggle('badge--fail', !passes)`

`setErrorState(isError)` function:
- `hexInput.setAttribute('aria-invalid', isError ? 'true' : 'false')`
- `hexInput.classList.toggle('input--error', isError)`
- `errorMsg.hidden = !isError`

Input handler on `hexInput` `input` event:
1. `const raw = hexInput.value.trim()`
2. `const parsed = parseHex(raw)` (imported from colour-engine.js)
3. If parsed is not null: `lastValidHex = expandHex(raw.replace(/^#/, ''))`, call `setErrorState(false)`, call `render(lastValidHex)`
4. If parsed is null: call `setErrorState(true)` — do NOT call render, panels keep last valid colour

DOMContentLoaded handler:
1. Set `hexInput.value = HEX_DEFAULT` (safety — HTML already has it)
2. Call `render(HEX_DEFAULT)`

Import statement at top of file:
```javascript
import { parseHex, contrastRatio, passesAA, passesAAA, passesAALarge, passesAAALarge } from './colour-engine.js';
```

Export the pure functions for testing:
```javascript
export { buildBadgeState, expandHex, formatRatio };
```
