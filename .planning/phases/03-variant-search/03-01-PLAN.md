    ## GREEN phase — implement variant-search.js

    Create `variant-search.js` as a pure ES module (no DOM, no window). Import from `colour-engine.js`.

    ### Constants
    ```javascript
    const LIGHT_BG = '#ffffff';
    const DARK_BG  = '#111111';   // Must match app.js DARK_BG — NOT #000000
    export const DISTANCE_WARNING_THRESHOLD = 0.12;
    const A_OFFSETS = [0, 0.01, -0.01, 0.02, -0.02];
    ```

    ### Helper: rgbToHex(r, g, b)
    Convert integer r,g,b (0-255) to 7-char uppercase hex string with # prefix:
    ```javascript
    function rgbToHex(r, g, b) {
      return '#' + [r, g, b]
        .map(v => Math.round(Math.min(255, Math.max(0, v)))
          .toString(16).padStart(2, '0'))
        .join('').toUpperCase();
    }
    ```

    ### Helper: searchL(L, a, b, direction, lightBg, darkBg)
    Binary search on OKLab L axis. Parameters:
    - L, a, b: starting OKLab coordinates
    - direction: 'darker' (search L toward 0) or 'lighter' (search L toward 1)
    - lightBg, darkBg: background hex strings

    Logic:
    1. Set lo/hi based on direction: darker → lo=0, hi=L; lighter → lo=L, hi=1
    2. Loop 40 iterations (sub-0.001 precision on L)
    3. Each iteration: mid = (lo+hi)/2, convert oklabToSrgb(mid, a, b), convert to hex via rgbToHex
    4. Compute contrastRatio(hex, lightBg) and contrastRatio(hex, darkBg)
    5. If passesAA on either ratio: save as result, continue searching TOWARD the original (darker: lo=mid, lighter: hi=mid)
    6. If fails: search AWAY from original (darker: hi=mid, lighter: lo=mid)
    7. Return hex string or null

    ### Gamut check
    After oklabToSrgb, round-trip: srgbToOklab the result and compare a/b channels to the input a/b. If |delta_a| > 0.02 or |delta_b| > 0.02, discard the result (gamut clipping shifted the colour identity).

    ### Main: findVariants(inputHex, count = 5)
    1. parseHex(inputHex) — return null if invalid
    2. srgbToOklab(r, g, b) to get origin {L, a, b}
    3. For each offset in A_OFFSETS: set a_shifted = origin.a + offset, keep b = origin.b
    4. For each a_shifted: run searchL in both 'darker' and 'lighter' directions
    5. For each valid result hex: compute oklabDistance between input rgb and result rgb
    6. Deduplicate by uppercase hex (Map keyed on hex)
    7. Sort by ascending distance
    8. Return first `count` results as array of { hex: string, distance: number }

    ### Export
    ```javascript
    export function findVariants(inputHex, count = 5) { ... }
    export { DISTANCE_WARNING_THRESHOLD };
    ```
