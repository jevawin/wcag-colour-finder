## Decisions Made

- **Paste stripped at source, not just at twin.** CONTEXT.md accepted twin-only stripping, but user feedback on Task 3 showed rich-text from Claude chat rendered with black backgrounds on the source panel. Fix intercepts paste, inserts plain text at caret via Selection API, dispatches synthetic input to reuse mirror.
- **No persistence kept.** User reported "refresh loses edits" but this is an explicit CONTEXT.md must-have truth. Left as-is.
- **Selection API over execCommand.** execCommand is deprecated; Range.insertNode + setStartAfter is the modern equivalent and works in all target browsers.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 — Bug] Rich-text paste rendered with source formatting, broke mirror reliability**
- **Found during:** Task 3 (human-verify checkpoint — user feedback)
- **Issue:** Pasting rich text from Claude chat into the source panel retained styled markup (black backgrounds, fonts). Browsers also do not reliably fire `input` for HTML paste across all paths, which made "desktop light dark don't say same" user-visible.
- **Fix:** Added a `paste` listener per specimen inside `wireSpecimenSync()`. preventDefault, read `clipboardData.getData('text/plain')`, insert a text node at the current Selection Range, then dispatch a synthetic `input` event so the existing mirror fires.
- **Files modified:** app.js (wireSpecimenSync paste handler, 25 lines added)
- **Verification:** `node --check app.js` passes; `grep innerHTML app.js` unchanged (no new uses); grep for `sr-status` unchanged; paste listener wired for all six runtime elements (3 classes × 2 panels inside the existing loop).
- **Committed in:** `98ed949`
