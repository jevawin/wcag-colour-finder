Replace the stub `colour-engine.js` with the full implementation. Single ES module, all named exports, no default export, no class. Per D-01 (ES modules), D-05 (American spelling in code identifiers), D-08 (return null on bad input).

**Constants:**
```javascript
export const AA_NORMAL  = 4.5;
export const AAA_NORMAL = 7.0;
export const AA_LARGE   = 3.0;
export const AAA_LARGE  = 4.5;
```

**parseHex(hex):** Per D-08, return `{r, g, b}` (integers 0-255) or `null`.
- Guard: `typeof hex !== 'string'` -> return null
- Strip leading `#`, trim whitespace
- If length 3, expand each char: 'abc' -> 'aabbcc'
- Regex gate: `/^[0-9a-fA-F]{6}$/` — reject anything else as null
- Parse with `parseInt(hex, 16)`, extract r/g/b with bit shifts

**relativeLuminance(r, g, b):** WCAG 2.1 formula.
- Threshold: 0.04045 (NOT 0.03928 — W3C correction, flagged in STATE.md)
- Exponent: 2.4
- Weights: [0.2126, 0.7152, 0.0722]
- Map each channel: `v /= 255; v <= 0.04045 ? v / 12.92 : Math.pow((v + 0.055) / 1.055, 2.4)`
- Reduce with luminance weights

**contrastRatio(hex1, hex2):**
- Parse both hexes. If either is null, return null (per D-08).
- Compute luminance for each.
- `lighter = Math.max(l1, l2)`, `darker = Math.min(l1, l2)`
- Return `(lighter + 0.05) / (darker + 0.05)`
- CRITICAL: Do NOT round. Return the raw float. Rounding before comparison would make #777777 falsely pass AA.

**passesAA(ratio):** `return ratio >= AA_NORMAL` (4.5)
**passesAAA(ratio):** `return ratio >= AAA_NORMAL` (7.0)
**passesAALarge(ratio):** `return ratio >= AA_LARGE` (3.0)
**passesAAALarge(ratio):** `return ratio >= AAA_LARGE` (4.5)

**srgbToOklab(r, g, b):** Ottosson matrices from https://bottosson.github.io/posts/oklab/
- Internal linearise helper: same sRGB linearisation as relativeLuminance (threshold 0.04045, exponent 2.4)
- M1 matrix (linear RGB to LMS):
  ```
  l = 0.4122214708 * rl + 0.5363325363 * gl + 0.0514459929 * bl
  m = 0.2119034982 * rl + 0.6806995451 * gl + 0.1073969566 * bl
  s = 0.0883024619 * rl + 0.2817188376 * gl + 0.6299787005 * bl
  ```
- Cube root each: `l = Math.cbrt(l); m = Math.cbrt(m); s = Math.cbrt(s);`
- M2 matrix (LMS to OKLab):
  ```
  L = 0.2104542553 * l + 0.7936177850 * m - 0.0040720468 * s
  a = 1.9779984951 * l - 2.4285922050 * m + 0.4505937099 * s
  b = 0.0259040371 * l + 0.7827717662 * m - 0.8086757660 * s
  ```
- Return `{L, a, b}`

**oklabToSrgb(L, a, b):** Inverse of srgbToOklab for Phase 3 search.
- Inverse M2 (OKLab to LMS):
  ```
  l = L + 0.3963377774 * a + 0.2158037573 * b
  m = L - 0.1055613458 * a - 0.0638541728 * b
  s = L - 0.0894841775 * a - 1.2914855480 * b
  ```
- Cube each: `l = l*l*l; m = m*m*m; s = s*s*s;`
- Inverse M1 (LMS to linear RGB):
  ```
  rl =  4.0767416621 * l - 3.3077115913 * m + 0.2309699292 * s
  gl = -1.2684380046 * l + 2.6097574011 * m - 0.3413193965 * s
  bl = -0.0041960863 * l - 0.7034186147 * m + 1.7076147010 * s
  ```
- Delinearise each channel (inverse of linearise): `v <= 0.0031308 ? 12.92 * v : 1.055 * Math.pow(v, 1/2.4) - 0.055`
- Clamp to 0-255, Math.round each
- Return `{r, g, b}`

**oklabDistance(rgb1, rgb2):**
- Convert both to OKLab via srgbToOklab
- Euclidean distance: `Math.sqrt((L1-L2)^2 + (a1-a2)^2 + (b1-b2)^2)`
